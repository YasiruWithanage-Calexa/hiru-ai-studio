# Block: contrast and affinity

**Source.** Bruce Block, The Visual Story (2nd ed., 2008)

**The idea.** Contrast in space, line, colour and movement raises intensity; affinity calms it. Plan the visual structure so that it rises with the story.

**What Adam takes.** A visual strategy per section of the treatment: calm sections share a size and a stillness, intense sections break them.

**Use it when.** Deciding where the scene should grow tense and where it should rest.

**Do not use it when.** Contrast everywhere: it stops meaning anything.
