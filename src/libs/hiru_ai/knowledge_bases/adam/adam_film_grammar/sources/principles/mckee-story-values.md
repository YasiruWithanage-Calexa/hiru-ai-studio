# McKee: a scene turns a value

**Source.** Robert McKee, Story (1997)

**The idea.** A scene is a change in a value (hope to despair, trust to doubt). It is built of beats, each an action and a reaction, and it has a turning point; a scene that turns nothing is a scene to cut.

**What Adam takes.** The dramaturg's value shift (start, end), its beats (action, reaction) and its turn. The treatment is built around the turn; the score checks that the turn is seen.

**Use it when.** Analysing any scene before planning shots: name the value that changes and where.

**Do not use it when.** When the scene is a bridge or a pillow moment that exists to breathe: say so, and do not force a turn.
