# Plant and payoff

**Ask it as.** How do I make a small gesture mean something later? How do I set up an object so it pays off? What is a Chekhov's gun in a teledrama?

**What it does to the viewer.** Shows an object or gesture early, neutral, so that when the script uses it the viewer feels the echo.

**Use it when.** An object the script already uses later: a phone, an envelope, a cup, a key. Plant it softly in a wide or the edge of a frame; pay it off with the same gesture and new meaning.

**Do not use it when.** When the object never appears again, or when the plant would draw attention to itself. The payoff must be a SCRIPT moment in this scene, or a later scene that is named.

**Allowed kind.** plant (elaboration)

**Veo feasibility.** good. Simple props on a flat surface render well; keep the plant soft and unlabelled.

**On a card.** A plant moment (elaboration, kind plant, objects: [the object], serves the payoff block) in an early card. Treatment: plant {object, plant_moment, payoff_moment}. The score checks the pair.

**Example (a Hiru-style scene).** Anudi's phone lies face-down on the bench in the first wide; at the end she turns it face-down again, and the same gesture now means something.
